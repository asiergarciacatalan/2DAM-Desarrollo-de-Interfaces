# 🎨 Desarrollo de Interfaces — 2º DAM

Asignatura **Desarrollo de Interfaces** del ciclo DAM. El trabajo principal es un **proyecto en equipo de 5 personas gestionado con Scrum**.

## 🚀 Proyecto en equipo: Delta-Ghost

👉 Repositorio del proyecto: **[danimachaco/Delta-Ghost](https://github.com/danimachaco/Delta-Ghost)**

Mis aportaciones en el Sprint 1:
- Creación del proyecto **Angular como PWA** (manifest, service worker, iconos).
- Definición del **árbol de carpetas** del frontend y del backend.
- Carpeta de **diseño y mockups**.
- **Limpieza y organización** del repositorio.

El equipo trabaja con historias de usuario como *issues*, plantillas de *pull request* y una memoria que se genera automáticamente en PDF con **GitHub Actions**.
